Help & About

Everything you need to know about using CampusPulse.

What is CampusPulse?

CampusPulse is a smart campus issue management system that helps students and staff report, track, and resolve campus problems quickly and efficiently. It combines QR location tags, intelligent prioritization, and status lifecycle tracking.

How does it work?

  1. Report an issue with details, location, and optional photo.
  2. Get a ticket ID (e.g. CP-1005) and track real-time progress.
  3. Staff reviews and updates the issue as work advances.
  4. Receive verified updates until it is marked Resolved.

Priority Scoring & AI Engine

Priorities are computed using user severity, detected safety hazard keywords (sparks, water leaks, gas, broken glass), location vulnerability (laboratories, restrooms), and wait time.

Local Fallback Mode: If Claude or Gemini API is unreachable, offline, or lacks an API key, CampusPulse deterministically scores the issue in Java so no report is ever blocked or lost.
